# Паветта Агент для Windows

Первый локальный MVP: приложение выбирает папку проекта, обращается к API Паветты и выполняет ограниченный набор действий на компьютере.

[Сайт](https://pawetta.com/ai/) · [Политика приватности](PRIVACY.md) · [Безопасность](SECURITY.md) · [Политика подписи](CODE_SIGNING.md)

Проект распространяется по лицензии Apache 2.0. Для работы чата нужен аккаунт Паветты; ключей API в репозитории и приложении нет.

## Что уже работает

- выбор папки проекта;
- безопасное параллельное чтение файлов только внутри выбранной папки;
- потоковые ответы и мгновенная кнопка остановки;
- поиск текста по проекту;
- предварительный просмотр записи файла;
- подтверждение каждой записи и команды;
- резервные копии изменённых файлов в каталоге данных приложения;
- отмена каждого записанного файла прямо из ленты;
- запуск PowerShell-команд в корне проекта;
- блокировка очевидно разрушительных команд;
- до десяти агентских шагов на одну задачу;
- параллельное выполнение независимых чтений и поисков.
- автоматическое уплотнение большого вывода команд без потери протокола и последних результатов.
- память текущего диалога: короткое продолжение относится к предыдущей задаче;
- самостоятельный выбор безопасного варианта, когда пользователь разрешил «сделать любой»;
- аватар Паветты в шапке и сообщениях агента.
- вход в аккаунт Паветты через Яндекс в отдельном защищённом окне;
- общий с сайтом баланс, расходы и счётчик запросов;
- локальная история задач с восстановлением переписки;
- экран лимитов агента;
- локальный журнал действий без содержимого запросов и файлов;
- запросы к моделям с авторизованной сессией Паветты.
- тихий автозапуск вместе с Windows без появления окна;
- один экземпляр приложения, системный трей и продолжение задач после закрытия окна;
- уведомление о завершении задачи, когда Паветта работает в фоне;
- отдельные переключатели автозапуска, трея и уведомлений в экране аккаунта.
- облегчённый фоновый запуск без создания окна и рендерера до первого открытия;
- защита активной задачи от приостановки Windows;
- проверка новой версии и безопасная ссылка на обновление внутри приложения.
- индекс файлов, языков, символов и правил проекта;
- точечные замены фрагментов вместо полного переписывания существующих файлов;
- автоматический запрос проверки после изменений;
- контрольная точка с откатом всех файлов одной задачи.
- итоговая стоимость каждого ответа с суммой всех внутренних шагов задачи.
- компактная геометрия интерфейса, типографика и диалоги в стиле веб-версии `/ai`.
- контролируемые HTTPS-запросы к внешним API с ограничением ответа;
- открытие сайтов и путей проекта, буфер обмена и запуск разрешённых приложений;
- защита от локальных адресов, небезопасного HTTP и скрытых внешних действий.
- параллельное исследование независимых файлов, папок и поисковых запросов;
- проверка локальных сайтов и HTTPS-страниц в изолированном браузере со сбором ошибок консоли и загрузки;
- структурированный итог задачи: изменённые файлы, проверки, страницы, стоимость, открытие результата, откат и продолжение.

## Участие в разработке

Перед pull request запустите `npm test`. О найденных уязвимостях сообщайте приватно через GitHub Security Advisories, а не в публичных issues.

## Подписанная сборка portable EXE

```powershell
$env:WIN_CSC_LINK='C:\secure\pawetta-code-signing.pfx'
$env:WIN_CSC_KEY_PASSWORD='пароль сертификата'
npm run dist
```

Обычная сборка принудительно требует доверенный сертификат подписи кода и после упаковки проверяет Authenticode. Готовый файл появится в `dist/Pawetta-Agent-1.0.0.exe`. Для локальной разработки без публикации можно явно запустить `npm run dist:unsigned`.

## Ограничения MVP

- поддерживаются только текстовые файлы до 300 КБ;
- предварительный просмотр пока показывает два текста рядом, без построчной подсветки;
- команды запускаются только после явного подтверждения пользователя.
