# Безопасность

Не публикуйте сведения об уязвимости в открытом issue. Используйте GitHub Security Advisories: вкладка Security → Advisories → New draft security advisory.

Укажите версию приложения, шаги воспроизведения, ожидаемое и фактическое поведение. Не прикладывайте реальные ключи, персональные данные или чужие файлы.

Поддерживается последняя опубликованная версия Паветта Агента.
