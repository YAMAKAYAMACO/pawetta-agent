# Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Подпись подтверждает, что опубликованный Windows-бинарник собран из исходников этого репозитория и не изменён после сборки.

## Роли

- Committers and reviewers: участники репозитория с правом записи.
- Approver: владелец репозитория [YAMAKAYAMACO](https://github.com/YAMAKAYAMACO).

## Правила

- Релизы собираются только автоматическим workflow из зафиксированного исходного кода.
- Секреты подписи не хранятся в репозитории.
- Перед релизом выполняются автоматические тесты.
- Подписанный артефакт после подписи не изменяется.
- Сетевое поведение и работа с пользовательскими данными описаны в [политике приватности](PRIVACY.md).
