# Политика приватности Паветта Агента

Паветта Агент работает с выбранной пользователем папкой на компьютере. Приложение не сканирует остальные папки автоматически.

## Какие данные используются

- Текст сообщений и результаты явно выполненных инструментов отправляются по HTTPS в API `pawetta.com`, чтобы модель могла выполнить задачу.
- Файлы проекта читаются только по запросу агента в рамках выбранной папки.
- Запись файлов, команды PowerShell, внешние API-запросы, открытие сайтов и запуск приложений требуют видимого подтверждения пользователя.
- Авторизация выполняется через сайт Паветты. Секреты и ключи API не встраиваются в приложение.

## Что хранится локально

На компьютере сохраняются настройки, история задач, резервные копии изменённых файлов и журнал типов действий. Содержимое запросов, файлов, токены авторизации и ответы внешних API в журнал действий не записываются.

## Внешние API

Агент может обратиться к публичному HTTPS API только после подтверждения. Запросы к localhost, локальной сети и небезопасному HTTP блокируются. Пользователь отвечает за данные, которые явно разрешает отправить стороннему API.

## Удаление данных

Локальную историю и журнал можно очистить в приложении. Данные аккаунта и серверную историю можно управлять на [pawetta.com/ai](https://pawetta.com/ai/).
